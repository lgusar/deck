# Deck

A TUI tool for managing servers. Primary purpose is to brush up on Python.

## Setup

This project depends on `uv`. Download and installation instructions are [here](https://docs.astral.sh/uv/getting-started/installation/).

Then run

```bash
uv venv
source .venv/bin/activate
```

To start the tool, run

```bash
uv run deck
```
